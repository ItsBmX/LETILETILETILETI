# Gato Cumple — GitHub Pages

Todos los archivos están en la raíz del repositorio, sin subcarpetas.

Sube el contenido de este ZIP directamente a la raíz de tu repositorio. Configura GitHub Pages en Settings → Pages → Deploy from a branch → main → /(root).

No cambies los nombres de los archivos. El juego usa rutas relativas como `gato.png` y `ambiente_5min.mp3`.

El navegador puede conservar el progreso de esta versión mediante localStorage; en una visita nueva comienza con las misiones pendientes.
